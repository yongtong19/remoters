# Desktop development

- Focus on the Windows and macOS clients. Keep macOS CI manually triggered and use a local Mac for routine checks.
- After any UI change, capture the main screen and each changed screen or important interaction state. Check the screenshots and include them in the handoff. Prefer the running desktop client. Label any screenshot captured in a browser or using a simulated session.
- Use fixture addresses, masked pairing codes, and synthetic remote desktop content in shared screenshots.
